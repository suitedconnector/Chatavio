# Chatavio Icons

This directory contains the icon files for the Chatavio - AI Chat Exporter extension.

## Required Icons:
- icon16.png - 16x16 pixels (favicon, toolbar)
- icon32.png - 32x32 pixels (Windows, Linux)
- icon48.png - 48x48 pixels (extension management)
- icon128.png - 128x128 pixels (Chrome Web Store)
- icon256.png - 256x256 pixels (high DPI displays)

## Design Guidelines:
- Use the Chatavio brand colors (blue theme similar to progress bar #38bdf8)
- Clean, modern design that represents AI/chat export functionality
- Should be recognizable at small sizes
- Professional appearance for Chrome Web Store

## Implementation:
Replace these placeholder files with your actual PNG icons before publishing to the Chrome Web Store.
